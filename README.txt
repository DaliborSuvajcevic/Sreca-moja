ZA MOJU SRECU — GitHub Pages

Sadrzaj:
- index.html
- assets/vas-dvoje.png (vasa fotografija)

Objava:
1. Raspakuj ZIP.
2. Uploaduj index.html i ceo assets folder u root GitHub repozitorijuma.
3. Otvori Settings → Pages.
4. Izaberi Deploy from a branch → main → /(root) → Save.

VAZNO: Nemoj uploadovati samo index.html — fotografija mora ostati u assets folderu
sa nazivom vas-dvoje.png, jer je stranica ucitava sa te putanje.
